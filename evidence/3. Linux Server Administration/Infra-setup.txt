# First Ubuntu box (manual AWS console)

This is the small Linux box I used before Terraform owned everything. If you want to repeat it by hand:

1. Create a VPC
2. Create a subnet
3. Create an internet gateway
4. Create a route table
5. Associate the subnet with that route table
6. Add a default route: destination `0.0.0.0/0` → the IGW
7. Security group, three inbound rules:
   - TCP 22 from `0.0.0.0/0` (lock this to your IP if you can)
   - TCP 80 from `0.0.0.0/0`
   - TCP 443 from `0.0.0.0/0`
8. Launch Ubuntu 24.04
9. Lock the key file:

```bash
chmod 400 shoplite-q3.pem
```

10. SSH in (IP will be whatever AWS gave you):

```bash
ssh -i shoplite-q3.pem ubuntu@13.215.46.100
```

## Docker on that box

```bash
sudo apt update
sudo apt install -y docker.io
sudo apt install docker-compose-v2
sudo apt install -y make

docker --version
docker compose version
```
