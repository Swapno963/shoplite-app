# Docker — run ShopLite on your machine

From the repo root. You need Docker and Make.

```bash
cd shoplite-app
```

Build every image in `docker-compose.yml`:

```bash
make build
```

Bring the stack up in the background:

```bash
make up
```

Smoke-test that the app actually answers:

```bash
make smoke
```

That runs `scripts/smoke-test.sh`.

Unit tests (uses `.venv/bin/pytest` if you have a venv, otherwise `python3 -m pytest`):

```bash
make test
```

When you are done:

```bash
make down
```

That stops the containers and tears down the compose network.
