# Ansible — from your laptop onto the nodes

Install Ansible (Ubuntu):

```bash
sudo apt-get update -y
sudo apt install software-properties-common -y
sudo apt-add-repository --yes --update ppa:ansible/ansible
sudo apt-get install -y ansible

sudo apt-get install -y locales
sudo locale-gen en_US.UTF-8
sudo update-locale LANG=en_US.UTF-8
export LANG=en_US.UTF-8
```

Put the bastion in known_hosts so the first SSH does not hang. After `terraform apply` the public IP changes — use the output, not this one blindly:

```bash
ssh-keyscan -H 13.215.252.241 >> ~/.ssh/known_hosts
```

Inventory is `ansible/inventory`. Update hosts to match Terraform (bastion, control plane, workers).

Can Ansible reach them?

```bash
cd ansible
ansible all -m ping
```

Syntax, then the real run:

```bash
ansible-playbook -i inventory site.yml --syntax-check
ansible-playbook -i inventory site.yml
```

That playbook prepares nodes, installs containerd/kubeadm, inits the control plane, joins workers, CNI, EBS CSI, ECR pull.
